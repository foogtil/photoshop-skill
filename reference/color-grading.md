# 按照片内容选择调色

在看过原图后使用此参考。先写出照片的问题和希望保留的特点，再选风格。
审美依据是主体、光线、色彩关系和用户要求；统计数据只帮助发现风险。

## 先诊断，再挑两个合理候选

| 看到的情况 | 可比较的候选 | 应保留/复查 |
| --- | --- | --- |
| 主体偏暗、室内画面沉闷 | natural 与 clean，中等强度 | 提亮主体，保留灯光氛围；暗部噪点和白墙色彩 |
| 白背景、雪景、柔和高调 | clean 与减弱 natural | 保留明亮感，避免把最暗百分位硬拉成黑色 |
| 反差大、天空亮而主体暗 | 减弱 natural 与逐张复合曲线 | 主体与天空都看；高光压缩不会重建已丢失细节 |
| 灰淡、景物层次不足 | natural 与适度 vivid | 适度加层次和彩度，避免绿叶/天空过饱和 |
| 原图已经鲜艳，含霓虹/舞台灯 | 低强度 natural 与逐张轻微曝光曲线 | 保留有意的彩色光，不用灰度均值校正 |
| 夕阳、暖室内光且希望更暖 | natural 与 warm | 原有光线与肤色；不把暖调强加给不相关照片 |
| 用户明确要求胶片感 | 减弱 film 与 natural 基准 | 抬黑与低彩度是否合适；不把风格当曝光修复 |
| 人像、物品需要真实颜色 | natural 与 clean | 肤色/商品色优先，避免凭全图均值推断白平衡 |

以上是候选方向，不能按文件名套用。`auto` 等于 natural 中性基线，不进行场景识别。
不同照片可以选不同风格；分组应依据相似光线、曝光、色彩和目的，而不是平均分配模式。

亮度、彩度和冷暖独立决定。先让主体曝光与层次合适，再观察是否需要自然饱和度；
仅当视觉或用户要求支持时加入 temperature/tint。
`strength` 可先试 `0.7..1.0`，极端照片优先减少效果或手动曲线，不默认加到 `1.5`。
显式 adjustments 是绝对覆盖，不随 strength 缩放，降低整体效果时也应检查这些字段。

## 样片比较与回调

选择覆盖不同问题的 1–3 张原图，各自提出两个有理由的候选并实机导出。
候选用独立输出目录，保留原图和 comparison/review 以便对照。

先看 comparison 整图，再放大原图与成品的相同区域：主体、肤色、灰白物体、天空、高饱和颜色和暗部。
给出选择理由，例如“clean 让室内主体更明亮，白墙仍中性，natural 的暗部层次不足”。
不要只说“分数更高”或“参数更强”。

分别完成两项判断：

- **审美**：主体是否突出、曝光是否符合场景、层次是否自然、色彩是否协调、肤色与中性色是否可信、是否符合指定风格。
- **技术**：review.json 是否提示新增剪裁、彩度跳变、意外中性色偏移、暗图继续压暗、无明显效果或尺寸/ICC 问题；
  结合放大图决定合理与否。技术 pass 不保证审美改善，明显像素变化也不保证更好看。

最多回调两次，每次针对原因：

| 问题 | 优先调整 |
| --- | --- |
| 主体仍暗 | 选 clean，或逐张提亮复合曲线中间调；避免单纯提高彩度 |
| 画面过硬、暗部细节少 | 减弱 strength，或放缓复合曲线暗部；取消硬黑点 |
| 高光新增大片剪裁 | 减弱提亮，轻压复合曲线高光，确认白背景/灯光是否合理 |
| 绿叶/天空/肤色过饱和 | 下调 vibrance/saturation；检查显式覆盖值 |
| 灰白变成明显蓝/黄/洋红 | 减弱或置零 temperature/tint；确认是调整还是场景彩光 |
| 没有可见改善 | 重新诊断具体问题，调整对应参数；不为制造差异加重所有项 |

两次后仍无法满意通过，交付较稳妥候选并说明具体未解决项。
脚本不会自动执行审美选择或参数回调，这些决定由查看实际图片后的判断完成。

## 批量验收

通过样片后给同类照片使用同组设置；特殊照片用 jobs 逐张调整，reason 记录可核对的原因。
检查全部导出状态，并查看每组代表照片及所有风险标记。
确认主体曝光与色彩有改善，未出现明显新偏色/细节丢失/过饱和，方向、尺寸、ICC 正确，源图完整。
报告实际采用的模式、强度、色彩或曲线参数和检查结论；不要宣称恢复了已剪裁信息。
